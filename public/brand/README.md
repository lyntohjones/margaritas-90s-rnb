# Brand assets

every brand graphic and stays fully functional without any file here.

See `docs/ASSET_REQUIREMENTS.md` for the full generation spec (exact
filenames, dimensions, crops, alt text, and copy-ready AI prompts) for the
files below. Once generated, drop them in here with these exact names:
