# Event media

REAL EVENT MEDIA — ADD AFTER LIVE EVENT

This folder is empty until the first live event happens. Do not add stock,
stand-in, or AI-generated "crowd" photography here — only real photography
and video from an actual Margaritas & 90s R&B event.

Naming convention:

```text
YYYY-MM-DD-edition-01.webp
YYYY-MM-DD-edition-02.webp
```

See `docs/ASSET_REQUIREMENTS.md` for the initial gallery batch this project
expects (`event-gallery-01.webp` … `event-gallery-04.webp`,
`event-recap-01.mp4`), all labeled REAL EVENT MEDIA — ADD AFTER LIVE EVENT.
